          How to use ShelfBridge

          A full walkthrough of getting your library out of Fable. Each section matches one of the three steps.

          Step 1: Connect to Fable

          Select Connect to Fable on the welcome screen. If you already have a Fable tab open, we use that one. If not, we open one for you. If you're not signed in to Fable yet, sign in there, then come back to this tab and select Connect again.

          ShelfBridge never sees your Fable password

          You sign in on Fable's own page, in your normal browser.

          Step 2: Review your library

          Select anything in the table to edit it. Changes save as you go, so there's no save button. You can:

          • Edit any cell: title, author, shelf, dates, rating or ISBN.
          • Rate a book, half stars included: select the left half of a star for the half, or the right half for the whole star. Select the same spot again to clear it.
          • Filter by shelf: use the buttons above the table. This only changes what you see; the export still has every shelf.
          • Sort the list: use Sort by to order it by title, author, finish date, start date or rating, either way round. Books with nothing to sort on, such as no rating, go to the bottom. Sorting only changes what you see, not the file.
          • Export only part of your library: set a From date, a To date or both. Books outside them are left out of your export, which helps if you moved to Fable from somewhere else and only want what you've logged since. A book is placed by its finish date, or its start date if it isn't finished. Books with no dates at all are left out unless you tick Include books with no dates.
          • Remove a book: select Remove at the end of its row.

          What the "Month only" badge means

          Fable only had the month or year for some dates, not the exact day. We've set the missing parts to the 1st, so you may want to correct the date yourself. The badge disappears once you do.

          Why some ISBN cells are highlighted

          A highlighted ISBN cell means the book has no ISBN we can use. Pagebound finds a book by its ISBN and nothing else, so those books are left out of a Pagebound file. Type the ISBN in and the highlight clears.

          Step 3: Pick where it's going

          Select Continue to export and choose a destination. Each one shows what comes across and what doesn't, and gives you the steps for importing into that app.

          • Goodreads: the original route, and the one most people have used.
          • StoryGraph: upload the file using StoryGraph's Goodreads import, because StoryGraph doesn't import its own files.
          • Pagebound: upload the file using Pagebound's StoryGraph option. It's the only one that keeps half stars.

          Why the file has the "wrong" name

          Files are named after their format, not the app. Choosing StoryGraph gets you a file with "goodreads" in the name, and choosing Pagebound gets you one with "storygraph" in it. That's correct. Upload them exactly as they are.

          Dates and ratings

          • Finish dates come across everywhere.
          • Start dates are left blank everywhere. None of the files these apps import has a column for one, so you'd add them by hand afterwards.
          • Half stars only survive on Pagebound. Goodreads can't store them, and StoryGraph rounds them on the way in.
          • Reviews don't come across anywhere.

          Can I send my library to more than one place?

          Yes. Your library stays here after you download, so you can go back to the export page, pick a different destination and download again. Nothing is used up.

          Privacy

          Everything runs in your own browser. Your books are stored in this browser's extension storage and never sent to a server we run. The only outside service is Fable's own API (api.fable.co), to read your shelves.
