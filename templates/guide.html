How to use ShelfBridge

A full walkthrough of moving your library from Fable to Goodreads. Each section matches one of the three steps. If something goes wrong, the troubleshooting tips further down cover the common problems.

Step 1: Connect to Fable

On the welcome page, select Connect to Fable. A second browser window opens by itself and shows Fable's sign-in page. Sign in there as you normally would on Fable's website. ShelfBridge never sees your password: you type it into Fable's own page.

Once you're signed in, come back to the ShelfBridge tab and select Connect again. ShelfBridge then reads your shelves from Fable's API. For most libraries this takes between 10 seconds and a minute.

You'll need to sign in again in the new window

The second window is a fresh Chromium browser. It doesn't share cookies with your normal browser, so you have to sign in even if you already have Fable open elsewhere. That keeps your password out of ShelfBridge entirely.

Step 2: Review your library

You'll see a table of your books, one row per title. Check everything looks right. Select anything to edit it. Changes save when you move away from the cell, so there's no save button.

What you can do here:

  • Edit any cell: title, author, shelf, dates, rating or ISBN.
  • Rate a book: select a star to set the rating. Select the same star again to clear it. Fable's web API doesn't share ratings, so unless you rated books in the iOS app this column starts empty.
  • Filter by shelf: the buttons above the table show just Read, Reading or Want to read.
  • Remove a book: select Remove at the end of its row, then confirm.

What the "Month only" badge means

A Month only or Year only badge under a date means Fable only knew the month or year, not the exact day. We've set the missing parts to the 1st so the date is still valid, but you may want to correct it. The badge disappears as soon as you edit the date.

Step 3: Export and import to Goodreads

Select Continue to export. The export page shows a preview of your file and what Goodreads does with each field. When you're ready, select Download Goodreads file. Your browser saves a file called goodreads_import.csv.

To get it into Goodreads:

  1. Open goodreads.com/review/import in a new tab.
  2. Select Choose file and pick the goodreads_import.csv you just downloaded.
  3. Select Import books. Goodreads takes a minute or two to process it.
  4. Your books appear in your Goodreads library, on the right shelves, with the right dates.

Dates and ratings

  • Date read in Goodreads is your Fable finish date.
  • Start dates are left blank. Goodreads' import has no "date started" column. The file puts your Fable start date in Date added, but Goodreads replaces that with the day you import, so you'd add start dates by hand afterwards.
  • Reviews don't come across. Goodreads' importer ignores review text, so we don't send it. Ratings, shelves and dates do come across.

Privacy

Everything in ShelfBridge runs on your own computer. It never sees or stores your Fable password: you type it into Fable's website, in the second browser window. Your books are stored in one file, books.db, in the ShelfBridge folder. Delete it to wipe everything. The only outside service ShelfBridge talks to is Fable's own API at api.fable.co, to read your books.

Troubleshooting

"Couldn't capture Fable's auth headers"

You probably weren't fully signed in to Fable when you selected Connect again. Sign out of Fable, refresh this page, select Try again and go through the connect step once more.

The browser window didn't open

Open your browser yourself and go to http://localhost:5050.

The Chromium window opens but Fable's sign-in page won't load

Check your internet connection. If it's working, open fable.co/login in your normal browser to check Fable itself is up.

"Port 5050 already in use"

Another copy of ShelfBridge is probably still running in another Terminal window. Close that window, then start ShelfBridge again.
