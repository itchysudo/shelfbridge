# ShelfBridge roadmap

This is what's planned for ShelfBridge, roughly in the order it'll arrive. Nothing here has a date on it, because ShelfBridge is a free tool built in spare time, but it's an honest picture of what's next. A lot of what ShelfBridge does today started as a suggestion from someone using it, so if there's something you'd like to see, [open an issue on GitHub](https://github.com/itchysudo/shelfbridge/issues/new) and say what you're trying to do.

## Up next

### Dates that open properly in spreadsheets

If you open your export in Excel or Numbers before importing it, some dates show up as `#####` or get turned into a different format. It's the most common question people ask, and the file itself is fine, but it's worrying when you see it. The fix is to write dates the same protected way ISBNs already are, so spreadsheets leave them alone, without changing what the importers receive.

### Progress shelf by shelf

While ShelfBridge reads your library you currently get a moving bar. The plan is to show each shelf as it's read, so you can see Finished, Currently reading and Want to read tick off one by one, and know it hasn't stalled on a big library.

## Recently shipped

Version 2.2610.1, in October 2026, brought a new look with dark mode, a date range so you can export just part of your library (requested on Reddit), and a Sort by menu for the library. Version 1.1, in August 2026, added StoryGraph and Pagebound alongside Goodreads, half-star ratings, and a safeguard that holds back books Pagebound can't identify. Open ShelfBridge and select **What's new** for the details.

## Got an idea?

[Open an issue](https://github.com/itchysudo/shelfbridge/issues/new) with what you'd like ShelfBridge to do and why. Requests from people actually moving their libraries are what decide what gets built next.
